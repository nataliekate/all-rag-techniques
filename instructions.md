# Installation Instructions

## Frontend Dependencies

To install the required npm dependencies for the React frontend components, run the following command in your terminal:

```bash
npm install lucide-react react-markdown remark-gfm clsx tailwind-merge
```

### Package Descriptions:
- **lucide-react**: A library of beautiful & consistent icons for React
- **react-markdown**: A React component for rendering markdown
- **remark-gfm**: A remark plugin to support GitHub Flavored Markdown
- **clsx**: A utility for constructing conditional className strings
- **tailwind-merge**: A utility for merging Tailwind CSS classes

Make sure you have Node.js and npm installed before running this command. If you encounter any permission issues, you may need to use `sudo` on Linux/macOS or run the command prompt as Administrator on Windows.
